VIDEOS FOLDER

videos/previews/  Short hover previews for project cards.
                  4-6 seconds, no audio, 1280px wide, under 1.5 MB, MP4 (H.264).
                  Point a project's  preview:  field at the file.

videos/           Full-length MP4s you host yourself (keep each under ~20 MB).
                  For longer films, upload to YouTube or Vimeo instead and use
                  { type: "youtube", id: "..." } in js/projects.js.
